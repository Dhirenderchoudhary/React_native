# Dhirender's Auth Platform 🚀

A premium, high-performance React Native authentication system built with Expo Router, TypeScript, and a sophisticated Midnight Emerald glassmorphism design. This platform serves as a production-ready starter for secure and beautiful mobile applications.

# Features

* **Expo Router v6**: State-of-the-art file-based navigation.
* **Midnight Emerald Theme**: A bespoke, premium dark aesthetic with glassmorphism effects.
* **TypeScript First**: Full type safety for robust development.
* **Responsive UX**: Optimized for all screen sizes with safe area support.
* **Keyboard Awareness**: Seamless form interactions on both iOS and Android.
* **Micro-interactions**: Polished button states and focus effects.
* **Expo Blur**: Deep glassmorphism using native blur effects.

# Installation & Setup

## 1. Clone the repository
```bash
git clone git@github.com:Dhirenderchoudhary/React_native.git
```

## 2. Install dependencies
```bash
npm install
```

## 3. Run the development server
```bash
npx expo start
```
